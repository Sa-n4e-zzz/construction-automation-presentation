# Автоматизация строительных процессов

Адаптивный сайт-портфолио о возможностях автоматизации в строительной компании: пять областей процессов, роли скриптов, ИИ и специалиста. Содержание основано на исходном перечне задач; приведённый сценарий является иллюстрацией подхода, а не демонстрацией работающей системы.

[Открыть сайт](https://sa-n4e-zzz.github.io/construction-automation-presentation/)

Сайт работает как статическая страница GitHub Pages без сборки и внешних зависимостей. Для локального просмотра можно открыть `index.html` в браузере. `styles.css` отвечает за адаптивную вёрстку, `script.js` добавляет только анимацию появления; содержимое доступно и при отключённом JavaScript. [Ранее подготовленная PDF-концепция](./presentation.pdf) сохранена для старых ссылок.
